# Archivist 条項ベースのドキュメント作成スキル

ソフトウェア開発ではさまざまな判断が積み重なる。そして条項の集積として、ADR(architectural Article Records)が積まれる。

しかし、このADR群はあくまで「部分解」的なものであり、**部分解の集合では実装に必要なドキュメント群になり得ない**。

部分解であるADRと実装方針書であるロードマップの中間には整理されない条項が残り、実装時に未考慮の部分を取りこぼす。
一方で実装時の判断が黙ったまま積もる危険性もある。

ここでは実装コードなどの客観的な事実と、それに基づくADRの条項を還元していくことで、実装に必要なドキュメント群を制定していく。
