# adoption — 取り込み

外にある決断の記述を読み、この文書系の決断として `L4_articles/` に置くこと。

- Aliases: 取り込み, 採択, ADOPTION
- Details: [reduction](reduction.md) と向きが違う。還元は決断から上層へ進み、
  取り込みは外から決断の層へ入る。archivist が回り始める前に済んでいる。
- Details: 採るかどうかは人が答える。取り込みが行うのは、既存の決断との
  突き合わせと、その結果の提示まで。
