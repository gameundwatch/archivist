# adoption — 取り込み

外にある条項の記述を読み、この文書系の条項として `L4_articles/` に置くこと。

- Aliases: 取り込み, 採択, ADOPTION
- Details: [reduction](reduction.md) と向きが違う。還元は条項から上層へ進み、
  取り込みは外から条項の層へ入る。archivist が回り始める前に済んでいる。
- Details: 採るかどうかは人が答える。取り込みが行うのは、既存の条項との
  突き合わせと、その結果の提示まで。
