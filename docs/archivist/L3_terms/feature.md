# feature — 機能

利用者が名指しできる単位。何を一つの単位とするかは決断が決める。

- Aliases: 機能, FEATURE
- Details: 何から導くかと、何を指すかは別のこと。feature は決断から起こし、
  仕様と設計を参照に持つ。下層を要約して得るものではない。要約として扱うと、
  還元が下から上へ進む都合上、分解を問い直す場面が残らなくなる。
