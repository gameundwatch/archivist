# pin — ピン

文書1枚を盤面に留めるための色と形。盤面の点、開いた紙、本文中の参照、凡例の
4箇所に同じものが現れる。

- Aliases: ノードの点, 色と形
- Details: 色と形の対応表は1つだけ置く。4箇所はその表だけを読む。
  色は層に、形は同じ層の中の割れ方に割り当てる。
  色だけで6つの区別を持たせない。色の識別には限界があり、層より細かい区別は
  色以外の手がかりを要る。
  文書のファイル名に付けていた `_` の印とは別の語になる。そちらは廃止されており、
  この語はホワイトボード上の色と形だけを指す。
