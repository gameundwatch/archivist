# structure — 構造

型や schema、コンポーネントの関係など、構造そのもの。

- Aliases: 構造, STRUCTURE
- Details: design を捨てても残る形だけを置く。決断の集合を写した一覧も置ける。
  判定は「その一覧を変えるのは決断か、実装か」で、決断なら structure になる。
  図に使う語は terms に在るものに限る。
