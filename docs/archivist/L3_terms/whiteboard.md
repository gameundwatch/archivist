# whiteboard — ホワイトボード

文書群の参照グラフを1枚の HTML として見るための生成物。`docs/archivist/` の文書と
索引から組み上がり、文書へは書き戻さない。

- Aliases: 盤面, whiteboard.html
- Details: 索引と同じく生成物で、層に属さない。消えても文書群は何も失わない。
  参照グラフを見るための道具であり、参照グラフを決める道具ではない。
  盤面上の位置は配置から毎回導かれる。手で動かした結果は残らない。
  読むものは `docs/archivist/` の `.md` と `index.csv` に限る。
