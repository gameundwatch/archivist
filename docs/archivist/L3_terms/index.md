# index — 索引

文書群の参照を1枚の表にしたもの。文書から機械的に組み直せる生成物で、
`docs/archivist/index.csv` に置く。

- Aliases: 索引, 参照表
- Details: 層に属さない。層は文書どうしの参照順序を定めるもので、索引は全ての層を
  横から一覧するため、順序の中に位置を持たない。
  文書1枚が1行に対応する。参照を持たない文書も1行を持つ。
  消えても何も失われない。毎回まるごと書き直し、差分を当てない。
  索引が在ることを他の文書の前提にしない。
