# reduction — 還元

決断の集合を読み、それが上層の文書に何を要求するかを書き起こすこと。

- Aliases: 還元, リダクション
- Details: 参照は上から下へ張るが、還元は下から上へ進む。この二つは別のものを指す。
  還元がどこで止まるかは決断の中身が決める。語だけを変える決断は L3 で止まり、
  その語を使う仕様があれば L2 まで上がる。
