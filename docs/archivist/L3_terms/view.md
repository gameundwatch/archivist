# view — 視点

ホワイトボードのどこを、どの拡大率で見ているか。盤面そのものとは別の状態になる。

- Aliases: 視野, カメラ
- Details: 掴んで動かす操作と拡大縮小の操作で変わる。
  拡大縮小はカーソルの下にあるものを固定点にする。拡大率を直接動かす手段は
  指す対象を持たないので、画面の中心を固定点にする。
  保存しない。開き直すと既定の視点に戻る。
  自動で追従させる仕組みを持つときは、手の操作が常に勝つ。
