# 決断が増減させる一覧は structure に置く

決断の集合を写した一覧は、要素が何個あっても structure に置ける。

structure に置けるのは design を捨てても残る形。一覧が「現在の姿の写し」なら
実装が変われば変わるが、**決断の写像**なら決断が変わったときにしか変わらない。
設計をいくら書き直しても行数は動かない。層の条件はこれで満たされる。

機能の増減は決断であり、その一覧は決断の像になる。像を抽象化して規則だけを残すと、
決断が増えたことが figure に現れなくなり、照合の対象も失われる。

判定はこう置く。**その一覧を変えるのは決断か、実装か。** 決断なら structure、
実装なら design に属する。
