# 参照は名前付きアンカーで張る

文書どうしの参照は `<a id="...">` で張る。行番号や見出しでは指さない。

揃えるための取り決め。別の指し方でも動くが、揃っていることに価値がある。

行番号は行が増減するとずれ、見出しは改名で切れる。アンカーは本文と独立に置けるので、
指される側を書き換えても切れない。

参照される側は、指される箇所の直前にアンカーを置く。参照する側は相対パスと
アンカー名で指す。id は文書内で一意にする。語を指すなら語そのもの、節を指すなら
主題を短く。

アンカーを置けないソースを指すときは、メソッド名などをコードブロックで指す。

decisions を指すときは `決定:` の行で書く。一文書一主題なのでファイルを指すだけで足りる。
