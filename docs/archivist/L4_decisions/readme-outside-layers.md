# README は層に属さない

`README.md` は `docs/archivist/` の外に置き、どの層のノードにもしない。

揃えるための取り決め。別の扱いでも動くが、揃っていることに価値がある。

層は文書どうしの参照順序を定めるもので、README はその外から L1_features を
網羅して読ませる入口になる。層に入れると L1 の上にもう一段を作ることになり、
「利用者が名指しできるものを一つとする」という feature の定義と重なる。

内容は L1_features の網羅であり、feature が増減すれば README も変わる。
いまその追随は人が行う。
