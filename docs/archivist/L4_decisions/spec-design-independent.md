# spec と design は互いを引かない

L2 の二つは対等な並列であり、参照を張らない。互いを待たずに書ける。

覆しにくい決定。

spec は What を、design は How を担当する。片方が他方を引くと、引かれた側の改訂が
引いた側を壊す。design が spec を引いていたのは、test を spec の側に押し出すため
だった。debug と test が別の層に着いた今、その理由は残っていない。

独立は参照グラフの話であって、整合の放棄ではない。両者が矛盾していないことは
feature が担保する。

並列に書けることを是とする。二つを同時に起こしても不備を生まない。
