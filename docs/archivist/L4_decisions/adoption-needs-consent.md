# 取り込むかどうかは人が答える

取り込みのスキルは、候補を既存の `L4_decisions/` と突き合わせ、一枚ずつ提示して
採否を人に問う。自分で採否を決めない。

覆しにくい決定。

写すだけなら `cp` で足り、スキルを設ける理由が無い。値打ちは突き合わせと、その
結果を人に見せるところにある。

[還元はするが、決断はしない](reduction-not-decision.md) がここにも効く。外から
来た記述を採るという判断は決断であり、代行すると、どの L4 文書にも現れないまま
上層に現れる。

一件ずつ問う形は件数に弱い。入力を絞るのは呼ぶ側の仕事で、取り込みの側は
件数を理由に一括の採択へ切り替えない。
