# 生成する文書の言語は対象プロジェクトに合わせる

archivist が書く文書の言語は、そのプロジェクトの既存の文書に合わせる。
テンプレートの言語では決めない。

覆しにくい決定。

テンプレートが英語であることと、生成される文書が英語であることは別になる。
テンプレートは形を示すもので、中身の言語まで決めない。決めてしまうと、
日本語のプロジェクトに英語の文書が生える。

既存の文書が無いときは、決断が書かれている言語に合わせる。決断は文書の起点であり、
そこに書き手の言語が既に現れている。

見出しと構造は英語で固定する。`## Requirements` `### Terms` `Means:` は
言語ではなく形にあたる。変わるのは散文だけになる。
