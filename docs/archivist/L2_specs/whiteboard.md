# whiteboard — ホワイトボードの要件

## Requirements

### R1 入力を文書と索引に限る

- 読むものは `docs/archivist/` の `.md` と `index.csv` に限る
- 索引が無くても文書だけから組める。索引はあれば使う

### R2 文書へ書き戻さない

- 起動の前後で `docs/archivist/` の `.md` が変わらない
- 盤面での操作の結果を、どのファイルにも保存しない
- 手で動かしたノードの位置は次に開いたとき残っていない

### R3 出力は1枚で完結する

- 出力は HTML 1枚で、他のファイルを読まずに開ける
- 開くときにネットワークを要らない

### R4 配置を複数持ち、切り替えられる

- 座標を決める規則を2つ以上持ち、閲覧中に切り替えられる
- 既定を1つ選ぶ。選ばれなかった配置も同じ盤面に差し込める
- 配置を1つ足すことが、他の配置の書き換えにならない

### R5 切り替えても注目は残る

- 配置を切り替えたとき、開いている紙は閉じない
- 切り替えたとき、注目しているノードは注目されたまま残る

### R6 ピンは1箇所から引く

- 盤面の点、開いた紙、本文中の参照、凡例の4箇所で、同じ文書は同じ色と形になる
- 色と形の対応を書いた場所が、出力の中に1つしかない

### R7 色だけに区別を負わせない

- 色は層に割り当てる
- 同じ層の中の割れ方は、色以外の手がかりで区別する

### R8 図は取得した実装が描く

- 文書の中の図は、生成時に取得した実装が描く
- 取得できなかったときは図を出さない。自前の描画に切り替えない
- 閲覧時に取得しに行かない

### R9 文書は盤面の上で開く

- 文書の中身は盤面の上に開き、開いた元のノードと繋がって見える
- 盤面の外の領域に文書ビューを持たない
- 2枚以上を同時に開ける

### R10 紙は2通りの操作で閉じられる

- 開いた元のノードを押すと閉じる
- 紙自身のピンを押すと閉じる

### R11 盤面を掴んで動かせる

- 背景を掴んで引くと、盤面全体が追従する
- ノードを掴んで引くと、そのノードだけが動く
- 自動で視点を追従させる仕組みが働いているとき、掴んだ時点でそれが外れる

### R12 拡大縮小はカーソルを固定点にする

- カーソルの下にあるものが、拡大縮小の前後で同じ位置に留まる
- 拡大率を直接動かす手段を併せて持ち、そちらは画面の中心を固定点にする
- 両者は同じ拡大率を指す。一方を動かすともう一方の表示も変わる

### R13 配置の切り替えは点の移動で行う

- 切り替えの間、点は消えずに新しい座標へ移動する
- 移動の途中でも盤面を掴める。移動の完了を待たせない

### R14 既定は画面より広い

- 既定の状態で、盤面の全体は画面に収まらない
- 拡大率を下げると全体が画面に収まる状態へ到達できる

### R15 視点を保存しない

- 開き直すと既定の視点に戻る
- 視点をファイルにも出力にも書き出さない

### V1 入力の限定

- Means: checklist
- 生成の入力が `docs/archivist/` の `.md` と `index.csv` だけであることを見る

### V2 索引なしでの生成

- Means: checklist
- `index.csv` を消した状態で生成し、同じノード数の盤面が出ることを見る

### V3 文書の不変

- Means: checklist
- 生成の前後で `docs/archivist/` の `.md` に差分が無いことを見る

### V4 位置の非保存

- Means: checklist
- ノードを手で動かしてから閉じ、開き直して元の配置に戻っていることを見る

### V5 単体での閲覧

- Means: checklist
- 出力を他のファイルから切り離し、ネットワークを断った状態で開き、盤面と図が出ることを見る

### V6 配置の切り替え

- Means: checklist
- 配置を切り替えると同じノードが別の座標に移ることを見る

### V7 配置の追加

- Means: checklist
- 座標を返す規則を1つ足し、既存の配置の記述を変えずに選べるようになることを見る

### V8 注目の持ち越し

- Means: checklist
- 紙を開いた状態で配置を切り替え、紙が閉じず、同じ文書が注目されたままであることを見る

### V9 ピンの一致

- Means: checklist
- 同じ文書について、盤面の点・紙のピン・本文中の参照・凡例の色と形が一致することを見る
- 対応表を1箇所書き換え、4箇所とも変わることを見る

### V10 色以外の手がかり

- Means: checklist
- 同じ層に属する2種類の文書が、色以外の手がかりで見分けられることを見る

### V11 図の描画

- Means: checklist
- 図を含む文書を開き、記法どおりに描かれていることを見る

### V12 取得失敗時の姿

- Means: checklist
- 取得できない状態で生成し、図を持たない出力になり、自前の描画が出ないことを見る

### V13 盤面の上での開き

- Means: checklist
- 文書を開くと盤面の上に出て、開いた元のノードと繋がって見えることを見る

### V14 複数枚の同時表示

- Means: checklist
- 2枚以上を開き、どちらも読める状態で並ぶことを見る

### V15 2通りの閉じ方

- Means: checklist
- 開いた元のノードで閉じられることを見る
- 紙自身のピンで閉じられることを見る

### V16 掴んでの移動

- Means: checklist
- 背景を掴んで引き、盤面全体が追従することを見る
- ノードを掴んで引き、そのノードだけが動くことを見る

### V17 手の操作の優先

- Means: checklist
- 自動追従を入れた状態で盤面を掴み、追従が外れることを見る

### V18 カーソル固定

- Means: checklist
- ある点にカーソルを置いて拡大し、その点が画面上で動かないことを見る

### V19 二つの手段の一致

- Means: checklist
- 拡大率を直接動かしたあとにカーソルで拡大し、続きの拡大率から変わることを見る

### V20 切り替え中の操作

- Means: checklist
- 配置を切り替えた直後、移動が終わる前に盤面を掴めることを見る

### V21 既定の広さと全体への到達

- Means: checklist
- 開いた直後、盤面の全体が画面に収まっていないことを見る
- 拡大率を下げると全体が収まる状態に到達できることを見る

### V22 視点の非保存

- Means: checklist
- 視点を変えてから閉じ、開き直すと既定の視点に戻っていることを見る
