# 参照はファイル単位で張る

文書どうしの参照は相対パスでファイルを指す。ファイルの中の位置は指さない。

一文書一主題なので、ファイルを指せば主題を指したことになる。位置まで指すと、
指す側が指される側の内部構造を知ることになり、指される側を書き換えるたびに
参照が切れうる。ファイルなら改名以外で切れない。

参照する側は相対パスとファイル名だけで指す。decisions を指すときは `決定:` の
行で書く。

アンカーを置くこと自体は妨げない。ただし置くのも維持するのも人の仕事で、
skill は生成も検査もしない。

ソースを指すときも同じで、ファイルを指し、必要ならメソッド名などをコードブロックで添える。
