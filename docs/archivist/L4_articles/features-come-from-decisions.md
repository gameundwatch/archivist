# 機能が何かは決断であり、下層の要約ではない

feature は L2 を要約して得るのではなく、決断から起こす。他の層と同じく
IN に決断を持つ。

機能の分解は仕様や設計から出てこない。出てくるのは「利用者が名指しできる
ものは何か」という問いへの答えで、これは製品が外に何を晒すかの決断にあたる。
motivation を洗い出す過程で必ずこの問いが立つ。

要約として扱うと、L1 が下層の書き方を追認する立場になる。還元は下から上へ
進むため、L1 に着く頃には分解を問い直す場面が残っていない。決断を入力に
置くことで、機能の分解が独立した判断として残る。

L2 への参照は引き続き張る。何から導いたかと、何を指すかは別のこと。
