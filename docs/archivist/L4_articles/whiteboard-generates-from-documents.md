# ホワイトボードは文書から生成され、文書を書き換えない

`docs/archivist/` の `.md` と `index.csv` だけを読み、`docs/archivist/whiteboard.html`
を出力する。文書にもコードにも書き戻さない。

出力は索引と同じ場所、層の6つのディレクトリの外に置く。生成物であり、どの層の
ノードでもないため。

参照グラフを見るための道具であり、参照グラフを決める道具ではない。書き戻せる
ようにすると、盤面での操作が文書の権威になる。条項から文書を組み直す向きと逆流する。

盤面で動かしたノードの位置も残さない。位置は配置規則から毎回導かれるもので、
文書が持つ情報ではない。消えて困るものを盤面に置かない。

`index.csv` が無くても文書だけから組み直せる。索引は速さのためにあり、
前提ではない。
