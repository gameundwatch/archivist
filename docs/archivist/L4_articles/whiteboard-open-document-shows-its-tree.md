# 開いている文書の周りは木として出す

盤面とは別に、開いている文書を根とした参照の木を出す。指している先と、指されている
元の両方を持つ。

盤面は位置で全体を見せるが、ある文書がどこへ繋がっていくかを順に辿ることは位置では
読めない。糸の先を目で追う操作は、枝が増えるほど当てにならない。木は順序を持つので、
辿ることがそのまま読むことになる。

木は開いている紙に追従する。ポインタで変えない。読んでいる最中に木が入れ替わると、
辿っている途中がどこだったか分からなくなる。

木は盤面を隠さない。面を持たず、行だけが操作を受ける。行の無いところは盤面のままで、
掴めば盤面が動く。

同じ文書が枝の中で再び現れたら、そこで枝を止める。参照は循環しうるもので、木は
循環を表現できないため。
