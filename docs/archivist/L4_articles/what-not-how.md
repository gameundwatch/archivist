# 整理するのは何を作るかであり、どう作るかではない

archivist が条文から導くのは、何を作るかだけ。どう作れば開発が進むかは、
導かないし、置き場所も与えない。

どう作るかは、誰が、いつ、何を持っているかで変わる。同じ条文から同じ答えが
出ない以上、それは条文からの還元ではない。還元でないものを還元の層に置くと、
層が何を意味するのかが崩れる。

混ぜたときの損は片側にしか出ない。何を作るかは滅多に変わらず、どう作るかは
毎日変わる。同じ文書に乗せれば、変わらない側が毎日読み直される。

外に置いても失われない。どう作るかは別の出処を持てる。archivist が覆わないと
宣言することは、その出処が要ると言うことでもある。
