# できあいの実装は生成時に取り込む

文書の記法も検索も、外部の実装に任せる。生成時に取得し、版を固定して出力へ埋め込む。
archivist はそれらを実装しない。

追随が終わらないものを自前で持たない。記法も検索も仕様と精度が外で動き続けるもので、
自前で解くと、対象プロジェクトの書いた記述や語が実装範囲を超えた時点で壊れる。
崩れる範囲を archivist が背負うことになる。

取得は生成時の一度きりにする。閲覧時に取りに行くと、出力を読める期間が外部の
可用性に縛られる。埋め込んだ後はネットワークを要らない。

取得できなかったものは、その働きを持たないまま出力する。代わりの実装を持たない。
解かれなかった本文は書かれたままの文字として出し、図は出さず、検索は現れない。
