# L4 の文書は条項と呼び、中身を制限しない

L4 に置く一枚を条項と呼ぶ。決断でも、揃えるための取り決めでも、語の定義でも
よい。何が置けるかを名前で絞らない。

決断という名前は、L4 が持つもののうち一種類しか指さない。定義を置こうとすると
名前と中身が食い違い、置き場を増やすか、名前を偽るかのどちらかになる。条項は
上位語で、どちらも収まる。

種類の違いに機械が分岐していないことが、ノードを割らない根拠になる。参照の
規則は L4 を一つの集合として扱う。割れば規則がどれも二重になり、
取り込みのたびに仕分けの義務が生まれる。その判定を使う側がいない。

どれか一種類だけを別に扱う規則が要るようになったとき、この条項は切れる。
